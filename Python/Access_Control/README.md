# Access Control System

A simple Python program that determines whether a person is allowed access based on their age and whether they have a valid ID.

## Features
- **Age Verification:** Checks whether the person is 18 or older.
- **ID Verification:** Checks whether the user has a valid ID.
- **Conditional Logic:** Uses the `and` operator to ensure both conditions are satisfied.
- **Access Decision:** Grants or denies access based on the given conditions.

## Access Rules
- **Age 18 or above + Valid ID:** Access Granted
- **Under 18:** Access Denied
- **No valid ID:** Access Denied

## How to Run

1. Ensure you have Python installed.
2. Clone this repository or download the `access_control.py` file.
3. Open your terminal and run:
   ```bash
   python access_control.py
