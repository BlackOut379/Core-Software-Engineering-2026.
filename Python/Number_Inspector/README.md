# Digit-by-Digit Number Inspector

A simple Python program that analyzes a positive integer and displays its digit count, digit sum, largest digit, and reversed number.

## Features
- **Digit Counting:** Counts the total number of digits using a `while` loop.
- **Digit Sum:** Calculates the sum of all digits using the modulo operator (`%`).
- **Largest Digit:** Identifies the largest digit in the given integer.
- **Number Reversal:** Reverses the integer using arithmetic operations without converting it into a string.
- **Looping and Arithmetic:** Uses `while` loops, integer division (`//`), and modulo (`%`) to process digits.
- **Functions:** Organizes the program into separate functions for each operation.
